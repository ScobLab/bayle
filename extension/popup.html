Pour analyser des articles, vous avez besoin d'une clé API Mistral gratuite.

Pas encore de clé ? Créez-en une gratuitement ▸
  1. Rendez-vous sur console.mistral.ai/api-keys
  2. Cliquez sur "Créer une nouvelle clé"
  3. Donnez-lui un nom (ex : "Bayle") et cliquez sur "Créer"
  4. Copiez immédiatement la clé affichée
  5. Collez-la dans le champ ci-dessus

Gratuit, sans carte bancaire.

Chargement de l'article...

L'article n'a pas pu être extrait automatiquement (page payante ou protection active). Copiez le texte de l'article et collez-le directement sur le site Bayle pour l'analyser.
